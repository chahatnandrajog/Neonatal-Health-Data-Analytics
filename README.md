# Neonatal Health Data Analytics

## Project Overview

This project uses publicly available CDC natality data to investigate neonatal health outcomes through SQL-based data management, statistical analysis, and interactive dashboards.

## Dataset

- **Source:** CDC WONDER Natality Data
- **Reporting Period:** 2019–2024
- **Data Type:** Aggregated birth statistics

## Technologies

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Tableau
- SAS / Python

## Project Progress

- [x] Imported CDC natality data into Microsoft SQL Server
- [x] Verified data import using SQL queries
- [ ] Clean and validate dataset
- [ ] Develop healthcare KPI queries
- [ ] Build Tableau dashboard
- [ ] Conduct statistical analysis

## Project Objectives

1. Analyze trends in neonatal health outcomes.
2. Develop SQL queries for descriptive healthcare statistics.
3. Create visualizations to communicate findings.
4. Explore statistical methods relevant to healthcare quality improvement.

## Data Source

CDC WONDER: https://wonder.cdc.gov/natality-current.html
